# Revisor-portugues-juridico

Skill do Claude para revisar textos jurídicos em português (petições, contratos, pareceres): clareza, pontuação, concordância, regência, crase, ortografia, ambiguidade e vícios de redação de IA.

Preserva as fórmulas de tratamento ao juízo ("Vossa Excelência", "Egrégia Câmara"), o endereçamento, o fecho, as expressões latinas e as citações literais (ementas, súmulas, leis). Arcaísmos de estilo pessoal são apenas sugeridos, nunca trocados.

## Instalação
1. Baixe este repositório (Code > Download ZIP).
2. Compacte a pasta `revisor-portugues-juridico` (ela deve conter o `SKILL.md`) em um .zip.
3. No Claude, vá em Configurações > Skills, envie o .zip e ative a skill.

## Uso
Cole o texto e peça a revisão. A resposta traz: resumo das alterações, texto revisado e sugestões pontuais.

## Aviso
A skill apoia a revisão, não a substitui. Confira sempre o texto final antes de protocolar ou enviar. Não cole dados sigilosos de clientes em ferramentas que você não tenha autorização para usar.
